# Repository Context

## What this repo does
This repository contains a browser-based Memory Game, also known as a Concentration card-matching game. Players flip cards to find matching pairs, complete the grid, and try to finish with the fewest moves and fastest time.

The game is implemented as a single HTML file with embedded CSS and JavaScript, making it lightweight, easy to run, and dependency-free.

## What it stands for
The project stands for a simple, accessible, and responsive web game experience built with core front-end technologies:

- HTML for structure
- CSS for layout and styling
- JavaScript for game logic and interactions

## Core features
- 4x4 and 6x6 board sizes
- Card flip animations
- Move counter and timer
- Star-based performance rating
- Best score tracking using local storage
- Keyboard navigation and accessibility support
- Responsive design for desktop and mobile screens

## Purpose of the project
The repo serves as a lightweight demo or learning project for:
- front-end game development
- DOM manipulation in JavaScript
- CSS animations and responsive UI design
- accessibility patterns in browser-based apps
- local storage usage for persistence

## File overview
- memory-game.html: main game implementation and UI
- README.md: project description and usage instructions
- PRD-dark-theme.md: product requirements for the dark theme feature

## How to run it
Open memory-game.html directly in the browser or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000/memory-game.html
```

## Summary
This repo is a small, polished memory-matching game designed to demonstrate interactive browser development with a focus on accessibility, responsiveness, and simple game mechanics.
